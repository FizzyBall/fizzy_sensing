The encoder mounts that were researched during this project are included here.
The pins of the Arduino encoders have to be connected as follows from the picture ConnectingPCBToEncoder.png.
The VCC is 3.3V
A standard Arduino encoder was used
The clamps (A AND B) are to be mounted with the flat faces somewhat aligned, this way the slots are around 90° phase shifted. 
The same hardware as the normal clamps can be used.
